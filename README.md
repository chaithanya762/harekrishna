## 🌅 Overview

**Sri Krishna & Puri Jagannath Divine Chanting Sanctuary** is a spiritual frontend web application built to offer a deeply calming, sacred Japa mala meditation experience. Unlike ordinary counter apps, this application recreates the atmosphere of ancient Indian temples with glowing diyas, incense smoke, temple light rays, and celestial soundscapes.

```
       🪷  NILACHALA NIVASAYA NITYAYA PARAMATMANE  🪷
 BALABHADRA SUBHADRABHYAM JAGANNATHAYA TE NAMAH
```

## ✨ Key Features

### 📿 1. 108 Japa Mala Counter & Dynamic Mantra Engine
- **108 Bead SVG Ring**: Trigonometrically calculated 108 circular beads with golden fill & milestone pulse animations at every 10 & 27 chants.
- **Central Royal Deity Frame**: Breathing golden halo frame exhibiting the active deity avatar.
- **Line-by-Line Mantra Sync**: Real-time typography highlighting active lines during chanting.

### 🧠 2. Soul Mood & Divine Guidance System
- Personalized spiritual blessings for 4 soul states:
  - 🙏 **Heavy Heart** *(Sorrow & Grief)*
  - 🌊 **Restless Mind** *(Worry & Anxiety)*
  - 🕊️ **Inner Peace** *(Deep Calm)*
  - 🔥 **Seeking Direction** *(Soul Guidance)*
- Automatic recommendation of Japa rounds (8, 27, 54, 108).

### 🪈 3. Vrindavan Web Audio Soundscape Synthesizer
- **Vrindavan Bansuri Flute**: Synthesizes expressively tuned flute notes in Raga scale using pure Web Audio sine oscillators & vibrato LFOs.
- **Temple Bells**: Harmonic dual-sine wave bell chime.
- **Om Fundamental Drone**: 136.1Hz Om tone with 272.2Hz octave resonance.
- *Zero external audio asset dependencies.*

### ☸️ 4. Dashavatara Katha & Sri Krishna Leela Gallery
- **10 Divine Incarnations of Sri Vishnu/Krishna**:
  1. 🐟 **Matsya Avatar** – Fish Incarnation saving Vedas
  2. 🐢 **Kurma Avatar** – Cosmic Tortoise bearing Mount Mandara
  3. 🐗 **Varaha Avatar** – Boar Incarnation lifting Earth Bhudevi
  4. 🦁 **Sri Ugra Narasimha Avatar** – Lion-Man slaying Hiranyakashipu while Prahlada prays
  5. 👑 **Vamana Avatar** – Dwarf Brahmin measuring three worlds
  6. 🪓 **Parashurama Avatar** – Warrior Sage eliminating tyranny
  7. 🏹 **Sri Rama Avatar** – Maryada Purushottama
  8. 🪶 **Sri Krishna Avatar** – Supreme Personality of Godhead
  9. 🌾 **Lord Balarama Avatar** – Incarnation of Spiritual Strength
  10. ⚔️ **Kalki Avatar** – Restorer of Satya Yuga
- **📖 Read Divine Katha Modal**: Deep stories, shlokas, and moral lessons for life strategy.
- **📿 Set Japa Deity**: Instantly set any Avatar or Leela as your active 108 Japa center deity!

### 📊 5. Per-Device Local Storage Persistence
- Daily reset logic, streak tracking, lifetime mantra count, and total sessions preserved locally per device.

### 📜 6. Non-Intrusive Footer
- `made with ❤️ by chaithanya` footer sits at the bottom end of scrollable pages and automatically hides during active Japa chanting sessions to eliminate distraction.

## 🛠️ Technology Stack

- **Core**: React 18, JavaScript (ES6+), HTML5
- **Styling**: Vanilla CSS3, CSS Custom Properties, Keyframe Animations, Glassmorphism
- **Audio Engine**: Web Audio API (Sine Oscillators, Gain Envelopes, LFO Vibrato)
- **Build Tool**: Vite 8
- **Icons & Typography**: Google Fonts (*Cinzel Decorative*, *Cinzel*, *Cormorant Garamond*, *Noto Serif Devanagari*)

## 🚀 Quick Start & Installation

```bash
# Clone the repository
git clone https://github.com/chaithanya762/harekrishna.git

# Navigate into project folder
cd harekrishna

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build & Deployment

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```

### Deploying to Vercel
1. Import `chaithanya762/harekrishna` repository into [Vercel](https://vercel.com).
2. Click **Deploy** (Vite settings detected automatically).
